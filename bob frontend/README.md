# Blackout sample website

A responsive HTML/CSS/JS concept for **Blackout — Predict power outages in your zone.**

## Run
Open `index.html` directly in a browser, or run:
```bash
python3 -m http.server 8000
```
Then visit http://localhost:8000

## Files
- `index.html` — page structure and sections
- `style.css` — responsive design, light/dark theme
- `script.js` — theme persistence, zone search demo, toast messages
- `assets/tower-light.png` — supplied hero image
- `assets/tower-dark.png` — separate dark-mode image generated from the supplied artwork

This is a front-end demo; map data, AI predictions, authentication, and APIs are mocked.
