# VOLTRA Agent Instructions

This repository contains the VOLTRA Predictive Grid Intelligence Platform.
Engineered for the Anand District Transmission Network and the Bobathon AI Hackathon.

## Tech Stack
- Frontend: React 19, TanStack Start & Router, Vite 8, TailwindCSS v4, Recharts, Lucide Icons.
- Backend: FastAPI (Python), scikit-learn, SHAP, IBM Bob (Claude 3.5 Haiku).
